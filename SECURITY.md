# Security policy

## Supported versions

Only the latest release gets security fixes.

## Report a vulnerability

Don't open a public issue. Report it privately instead, through [GitHub's vulnerability reporting](https://github.com/firatciftci/daybar/security/advisories/new).

Include the Daybar and macOS versions, what you found, and the steps to reproduce it. You'll get a reply within a week. Once a fix ships, the advisory is published with credit to you, unless you'd rather stay anonymous.
